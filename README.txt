WEEK 1 ASSIGNMENT – THREE WEBPAGES WITH NAVIGATION

Pages:
1. index.html – Home page
2. about.html – About, education and skills page
3. contact.html – Contact details and message form

Shared file:
- style.css – Styling used by all three pages

How to run:
1. Extract this ZIP.
2. Open the extracted folder in VS Code.
3. (Optional) Add your photo in this folder and name it profile.jpg.
4. In contact.html, replace your.email@example.com and add your LinkedIn profile URL.
5. Open index.html in a browser, or use VS Code Live Server.
6. Test navigation by clicking Home, About and Contact in the top menu.

Note:
The contact form uses a mailto action. It opens the visitor's default email app; it does not store messages on a server.
